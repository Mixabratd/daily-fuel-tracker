# Daily Fuel Tracker

i want you to build a mobile app for daily calorie and macros tracking, which gonna be able to use mobile camera for scanning food barcodes and logging daily food. first, lets focus on the app itself with few categories - home page with daily calories visible, second page where we log meals, third page will be targets, weight calculator and etc and last one will be settings page. Build only the foundation of the app and later we gonna put the more hard functions to implement with camera usage.
